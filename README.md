# Não Passe Daqui · DontPassHere

Mostre uma foto, um PDF ou uma pasta inteira com o celular bloqueado, mantendo a apresentação restrita ao conteúdo escolhido.

- **Nome no Brasil:** Não Passe Daqui.
- **Nome em inglês:** Don't Pass Here.
- **Repositório e arquivos de distribuição:** DontPassHere.

## Páginas oficiais

- [Site e tutorial](https://haduka1.github.io/DontPassHere/)
- [Política de privacidade](https://haduka1.github.io/DontPassHere/privacidade.html)
- [Suporte](https://haduka1.github.io/DontPassHere/suporte.html)

Este repositório contém as páginas públicas do produto. A publicação do aplicativo no Google Play está em preparação.

## Suporte e privacidade

O suporte está disponível nas [Issues deste repositório](https://github.com/Haduka1/DontPassHere/issues). As mensagens são públicas: não envie documentos pessoais, senhas, dados bancários ou imagens com informações sensíveis.

O aplicativo processa os documentos localmente para importação, armazenamento protegido e visualização. Consulte a política para conhecer o funcionamento do app e a diferença em relação à hospedagem deste site no GitHub Pages.
